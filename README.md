# MoneyControl — облік надходжень і витрат у Google Таблиці

Адреса додатку: **https://ivanpavlenko373.github.io/moneycontrol/**

Мобільний веб-додаток (PWA), який зберігає дані у вашій власній Google Таблиці.
Сервера немає: браузер працює напряму з Google Sheets API від вашого імені.

## Можливості

- Вхід через Google. Додаток сам створює нову таблицю з потрібною структурою і далі працює з нею.
- Кілька гаманців у різних валютах, кожен з початковим залишком і поточним балансом. Гаманець можна архівувати.
- Записи трьох типів: **витрата**, **надходження**, **переказ** між гаманцями (з різними сумами, якщо валюти різні).
- Поле **контактної особи** з підказками з бази раніше введених: часті та нещодавні імена йдуть вище. Нові контакти автоматично потрапляють на аркуш «Контакти».
- Поле **коментар**, дата, редагування й видалення записів.
- У полі суми працює арифметика: `120+35,5` → `155,50`.
- Фільтр за гаманцем, пошук за контактом, коментарем або сумою, підсумок руху за поточний місяць.
- Робота без інтернету: зміни стають у чергу і відправляються, щойно зʼявиться звʼязок.
- Встановлюється на головний екран смартфона як застосунок. Є світла й темна тема.

## Структура таблиці

| Аркуш | Колонки |
|---|---|
| **Транзакції** | ID · Дата · Тип · Гаманець · Сума · Гаманець-отримувач · Сума зарахування · Контакт · Коментар · Створено · Змінено |
| **Гаманці** | Назва · Валюта · Початковий залишок · **Баланс** (формула) · Архів · Створено |
| **Контакти** | Імʼя · Примітка · Створено |

Таблицю можна редагувати і вручну. Не змінюйте назви аркушів і порядок колонок. Рядкам, доданим вручну без ID, додаток сам присвоїть ID.

## Налаштування (≈15 хвилин, один раз)

### 1. Google Cloud: проєкт і API

1. Відкрийте <https://console.cloud.google.com/> і створіть новий проєкт (наприклад, `wallets`).
2. **APIs & Services → Library**: знайдіть і увімкніть **Google Sheets API** та **Google Drive API**.

### 2. Екран згоди OAuth

1. **APIs & Services → OAuth consent screen** (у новому інтерфейсі це **Google Auth Platform**).
2. Тип користувачів: **External**. Вкажіть назву додатку і свою пошту.
3. Розділ **Audience → Test users**: додайте свій Gmail.
   Інший варіант — натиснути **Publish app**. Додаток використовує лише scope `drive.file`, який не вимагає перевірки від Google.

### 3. OAuth Client ID

1. **APIs & Services → Credentials → Create credentials → OAuth client ID** (або **Clients → Create client**).
2. Тип: **Web application**.
3. **Authorized JavaScript origins** — адреса, з якої відкриватиметься додаток, без шляху і без слеша в кінці:
   - `https://ivanpavlenko373.github.io` (GitHub Pages; шлях `/moneycontrol/` тут не вказується)
   - `http://localhost:8080` (для локальної перевірки)
4. **Authorized redirect URIs** — `https://ivanpavlenko373.github.io/moneycontrol/` (саме так, зі слешем у кінці). Для локальної перевірки додайте ще `http://localhost:8080/`.
5. Скопіюйте **Client ID** (`…apps.googleusercontent.com`) у файл `js/config.js`:
   ```js
   CLIENT_ID: '1234567890-xxxx.apps.googleusercontent.com',
   ```

### 4. Публікація на GitHub Pages — `deploy.bat`

Запустіть `deploy.bat` подвійним кліком. Скрипт:
1. ініціалізує git-репозиторій у папці (якщо його ще немає) і привʼязує `origin` до `https://github.com/ivanpavlenko373/moneycontrol.git`;
2. комітить усі зміни і пушить у гілку `main` (при першому пуші Git Credential Manager відкриє браузер для входу в GitHub);
3. вмикає GitHub Pages з гілки `main`, папка `/` — через GitHub CLI (`gh`). Якщо `gh` не встановлено, скрипт відкриє сторінку **Settings → Pages**, де це робиться двома кліками (Source: *Deploy from a branch*, Branch: `main` / `(root)`).

Встановити GitHub CLI: `winget install --id GitHub.cli`, далі один раз `gh auth login`.

Після кожної зміни файлів просто запускайте `deploy.bat` ще раз — він закомітить і опублікує нову версію. Сайт оновлюється через 1–2 хвилини.

> Репозиторій публічний, тож `CLIENT_ID` у `js/config.js` буде видно всім. Це нормально: Client ID не є секретом, а вхід дозволено тільки з адрес, вказаних в Authorized JavaScript origins.

### 5. На смартфоні

1. Відкрийте https://ivanpavlenko373.github.io/moneycontrol/ у Chrome (Android) або Safari (iPhone).
2. Натисніть **Увійти через Google** і дозвольте доступ.
3. Створіть нову таблицю. Якщо таблиці, створені цим додатком, уже є, їх можна вибрати зі списку.
4. Меню браузера → **Додати на головний екран**.

## Локальна перевірка

```bash
cd MoneyControl
python3 -m http.server 8080
```
- `http://localhost:8080/?demo=1` — демо-режим без Google, дані лише в браузері.
- `http://localhost:8080/` — повноцінна робота (потрібен CLIENT_ID з `http://localhost:8080` в origins).

## Важливо знати

- **Доступ.** Додаток має scope `drive.file`, тобто бачить тільки файли, які сам створив. Інших ваших документів він не бачить.
- **Сесія.** Google видає токен на 1 годину і без сервера не дає його тихо продовжити. Коли токен спливає, зверху зʼявляється жовта смужка «Увійти». Одне натискання переносить на Google і одразу повертає назад. Записи, зроблені до цього, не губляться: вони чекають у черзі на телефоні.
- **Вхід** відбувається через перенаправлення на сторінку Google і назад, без спливаючих вікон, тож працює на iPhone і Android, з головного екрана і з посилань у месенджерах. Якщо Google показує `redirect_uri_mismatch`, адреса в Authorized redirect URIs не збігається з адресою додатку.
- **Кілька пристроїв.** На іншому телефоні чи компʼютері увійдіть тим самим акаунтом і виберіть наявну таблицю зі списку.
- **Версія додатку** задається в одному місці — `js/version.js` (там же коротка історія змін). Її видно в меню ☰ → «Про додаток». Після будь-яких змін збільшуйте версію: від неї залежить оновлення кешу на телефонах.

## Безпека

- **Де дані.** Кожен користувач зберігає дані лише у власній Google Таблиці. Сервера, бази даних чи аналітики в додатку немає, тож витоку «з нашого боку» бути не може.
- **Доступ.** Scope `drive.file` дає додатку доступ лише до файлів, створених ним самим. Решту Google Drive він не бачить.
- **Вхід.** Токен Google діє 1 годину, вхід можливий лише через адресу з Authorized redirect URIs, запит захищено параметром `state`.
- **Код.** Сторонніх скриптів немає. Політика CSP дозволяє виконувати лише власні файли й звертатися лише до Google API. Дані з таблиці екрануються перед показом. Додаток не відкривається всередині чужих сайтів.
- **Що робити власнику:**
  - увімкнути двофакторну автентифікацію на GitHub і в Google-акаунті, з якого керується Google Cloud. Хто отримає доступ до репозиторію, зможе підмінити код для всіх користувачів;
  - не публікувати інші проєкти на `ivanpavlenko373.github.io`: усі сторінки цього домену мають спільне сховище браузера. Для сторонніх експериментів краще окремий акаунт або власний домен;
  - не додавати в репозиторій колабораторів, яким не довіряєте.
- **Що знати користувачам:** відкривати лише `https://ivanpavlenko373.github.io/moneycontrol/`. Копія додатку на іншій адресі може бути фішинговою. На чужому пристрої після роботи натискати «Вийти з акаунта».
